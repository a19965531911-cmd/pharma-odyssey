# 起源学院 V0.4 实际验证记录

日期：2026-10-22。状态：美术修复候选版，尚未满足全部 V0.4 成品验收条件。

## 实际修改及原因

原 GLB 的木材、石材、黄铜和纸张依赖 Blender 程序节点，导出后缺少可用的基础颜色或贴图；同时导出了强度约 3532–5435 的七盏灯，并与运行时灯光叠加。两者共同造成灰白、细节丢失。

现已把材质转换成打包的 PBR 颜色贴图，保留粗糙度与金属度差别；大厅 GLB 不再导出灯光，运行时统一布光。移除了 CSS 亮度滤镜和任意压暗材质的补丁。加入接触遮蔽、冷暖光照、窗面海岸图景，按实际几何调整镜头构图。窗面图景是局部材质，不是用离线大厅图片替代三维场景。

同步更新大厅 Blender 源工程与 GLB、角色批处理网格、书架后的真实通道与碰撞边界、紧凑 HUD、对话头像与单实例图鉴。修复了关闭课程和图鉴后的探索恢复，以及镜头到位后持续微小移动的问题。

## 检查范围

`npm run check`：29 项测试通过，lint、TypeScript 和生产构建通过。构建存在主 JS 超过 500 KB 的提示。

教学浏览器回归覆盖四区八课的七步流程、机制交互、双语、Boss 失败重试与奖励、图鉴、错题、XP，以及保存、恢复、迁移、损坏数据保护和导入。结果见 [learning/results.json](learning/results.json)。它直接进入教学，不等于完整探索通关。

大厅浏览器验证覆盖实时画布像素、NPC 接近与对话、图鉴单实例与关闭恢复、机制仪器接近、绕书架路线及截图。脚本为 `tests/hall-visual.cjs`。交互截图运行完成绕行与返回后，在性能采样的默认 30 秒等待处超时，因此该整轮不能记为全通过。随后独立执行 `VISUAL_MEASURE_ONLY=1` 的渲染、120 帧性能和参考截图检查，通过且没有 pageError。

## 性能实测

[原始记录](../art/validation/v04/performance.json)：1920×1080、DPR 1、无头 Chromium，实际渲染器为 ANGLE Vulkan SwiftShader 软件设备。120 个样本，平均 677.75 ms / 帧（约 1.48 FPS），P95 为 750 ms，340 次绘制调用、约 102 万计数三角形（含多遍渲染），场景加载约 1953 ms。采样时另有教学回归进程运行，存在资源争用；该结果既不代表独立显卡性能，也不能被当作性能通过。性能验收未通过，需要硬件加速环境复测及后续优化。

## 未完成与限制

- 未验证从雨夜码头经全部剧情门槛、八课、Boss 到完整结尾的连续人工或自动通关。
- 角色仍使用现有风格化几何模型，尚未达到要求的正式人物精细度；表情、动画与外观选项未全部重制。
- 窗外仍为窗面图景，未完成完整立体外景；空气尘埃与体积光尚不完整。
- 桌面构图已有改进，但仍能看到模型边界与单色背景；不能宣称完全解决展示台感。
- 移动端纵向探索场景偏小，尚未验收。
- 没有普通 PC GPU 的稳定 60 FPS 证据。无头浏览器结果只代表记录的运行环境。
- 项目同时出现的 world03 内容保留在源码中，其完整流程不属于本轮已验证范围。
- 蓝白色屏幕角落角色未在项目资源中找到，浏览器截图也未出现；未擅自更改外部悬浮层。游戏内 Lumi 保持既有黄铜灯灵身份。

### 本次位置修复

药效机制塔中 Lumi 原先位于双球仪上方偏近位置，导致角色标签和“双球仪”交互标签视觉重叠。已将 Lumi 移到左侧空位 `(-2.2, 0.4)`，双球仪保持中央位置。1366×768 自动复验确认两个标签不重叠，Lumi 对话和双球仪受体课程均可分别触发，证据见 [pd-spacing/results.json](pd-spacing/results.json) 与 [pd-spacing/separated.png](pd-spacing/separated.png)。

构建可运行与测试通过不代表上述未完成事项已经完成，也不代表视觉品质已获用户认可。
